# Yosys + OpenSTA flow report

Generated by `flow/report.py` from the files in `results/` (`make report`). Do not edit by hand.

## Setup

- **Synthesis:** Yosys 0.33 (git sha1 2584903a060): `synth -flatten`, `dfflibmap`, `abc -liberty` (`flow/synth.tcl`).
- **Timing and power:** OpenSTA 3.1.0 (built from source, commit 7633e96f).
- **Gate-level simulation for power:** Icarus Verilog version 12.0 (stable).
- **Cell library:** `sky130_fd_sc_hd__tt_025C_1v80.lib`, SkyWater 130 nm `sky130_fd_sc_hd`, corner tt (typical), 25 C, 1.80 V.
- **Constraints:** `flow/mul_wrap.sdc`: 10.0 ns clock on `clk`, input and output delay 0, ideal clock (no clock tree).
- **Wrapper:** each multiplier sits in `rtl/mul_wrap.sv` between input flip-flops (8 + 8) and output flip-flops (16). Multiplier area = total cell area minus those flip-flops.
- **Power stimulus:** 5,000 clock cycles of uniform random inputs; activity on all 956 pins comes from the simulation (none estimated).
- **Pre-layout:** no wire parasitics. Compare designs with each other (relative to N = 0), not with numbers from other tools or processes.

## Limitations

- Pre-layout: no wire capacitance and an ideal clock, so absolute delay and power will change after place-and-route.
- Zero-delay simulation: glitches are not counted, so dynamic power is underestimated for all designs alike.
- Uniform random inputs are not typical of image or CNN data.
